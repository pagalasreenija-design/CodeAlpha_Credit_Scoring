# 💳 Credit Scoring System

A Machine Learning based Credit Scoring System that predicts whether a customer is creditworthy based on financial and personal information.

## 📌 Project Overview

This project was developed as part of the CodeAlpha Machine Learning Internship.

The system uses a classification machine learning model to analyze customer financial information and predict creditworthiness.

The project includes both:
- A Machine Learning model for prediction
- A Flask web application for user interaction

## 🎯 Objective

The main objective of this project is to predict an individual's creditworthiness using financial data such as:

- Age
- Income
- Loan Amount
- Credit Score
- Payment History
- Employment Years

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML
- CSS
- Pickle
- SQLite/CSV-based data handling

## 🤖 Machine Learning

The project follows these steps:

1. Load the credit scoring dataset
2. Perform data preprocessing
3. Prepare the required features
4. Train a classification model
5. Evaluate the model
6. Save the trained model using Pickle
7. Use Flask to create a web interface
8. Accept customer details from the user
9. Predict creditworthiness
10. Display the prediction and probability

## 📊 Model Evaluation

The model was evaluated using:

- Accuracy
- Precision
